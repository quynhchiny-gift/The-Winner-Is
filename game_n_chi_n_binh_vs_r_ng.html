Hướng Dẫn Xuất Bản Lên GitHub Pages

  1. Bước 1: Tải file game
    Lưu toàn bộ mã nguồn file này thành tên: index.html.
  2. Bước 2: Tạo Repository trên GitHub
    Đăng nhập GitHub → Bấm New Repository → Đặt tên kho lưu trữ (ví dụ: nu-chien-binh-vs-rong-do) → Chọn Public → Bấm Create repository.
  3. Bước 3: Tải file index.html lên
    Bấm nút uploading an existing file → Kéo thả file index.html (và các file ảnh nếu có) → Bấm Commit changes.
  4. Bước 4: Bật GitHub Pages để có Link Chơi Game
    Vào mục Settings của Repo → Chọn tab Pages ở cột trái → Tại Build and deployment / Branch, chọn main (hoặc master) → Bấm Save.

Sau 1-2 phút, GitHub sẽ cấp cho bạn một đường link đường dẫn (URL) để gửi cho bất kỳ ai chơi game trực tiếp trên trình duyệt!
